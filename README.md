# Pepper Pass · 川味夜市

解压后用桌面浏览器打开 `game/index.html` 即可离线游玩，无需安装依赖。界面为英文，以下是中文操作指南。

1. 看右边最上面的订单；按 **1–6** 或点击选齐三种食材。第一次选食材时，90 秒倒计时启动。
2. 按 **Q** 两次切配，再按 **W** 开火。
3. 温度进入绿色区时按 **E** 装盘，按 **Enter** 上菜。绿色区的中段得分更高；过火会扣分。
4. 按 **X** 清空当前工位，不会取消订单。做对可以累计连击；一轮结束可重新开张。
5. 所有动作均有鼠标按钮。声音默认关闭，点 Sound Off 可以开启。

`screenshots/` 为实际浏览器画面：装盘、备菜和炒制。若要构建本地评审材料，可用 Node.js 22.18+ 运行
`MAKEFUN_OUTPUT_DIR=out node main.ts`。这只在本机生成材料，不登录、不上传、不参赛。
`test_game.py` 是 Playwright 冒烟测试，需要 Python、Playwright 和 Chromium。

这是独立的可玩构建，没有向 Make.fun 提交任何资料。
